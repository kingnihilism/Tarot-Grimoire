# Contributing

Marcy's Deck Grimoire is a personal project built with HTML, CSS, and vanilla JavaScript.

## Project Structure

The main application is contained in `index.html`.

The file includes:

- CSS styles
- HTML interface sections
- Card and deck data
- Spread templates
- JavaScript application logic

## Making Changes

1. Edit `index.html`
2. Open it in a browser
3. Test the affected feature
4. Check the browser console for errors
5. Commit changes with a descriptive message

## Important Conventions

- Use `deck::cardname` for deck-specific card identity
- Use `openModalByIndex()` for card modal opening
- Update export/import logic when adding persistent localStorage data
- Keep the application functional offline
- Update `CHANGELOG.md` when adding or fixing user-facing features

See the GitHub Wiki for architecture, data models, spread templates, search, statistics, and data management.
