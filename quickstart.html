# Quick Start ## Setup — About 30 Seconds 1. Download `deck_grimoire.html` 2. Open the file in Chrome, Firefox, Safari, or Edge 3. Start using the application No installation, account, server, or internet connection is required. --- ## First Things to Do ### Browse Your Decks Select any deck from the navigation bar. Each deck page includes: * A deck profile explaining its role in the system * Jump navigation for suits, temples, or card groups * Clickable cards that open detailed reference modals * Upright, reversed, shadow, or reflective meanings depending on the deck ### Add Personal Card Notes Click any card to open its detail modal. Enter your observations in the personal notes field. Notes save automatically to your browser and remain separate for cards with the same name across different decks. ### Add Deck-Specific Major Arcana Meanings Major Arcana cards from the Sailor Moon and Erotic Tarot decks include editable fields for deck-specific upright and reversed meanings. Use these fields to record how the same Major Arcana card reads differently in each deck. Your entries save automatically in browser storage and are included in exported backups. ### Search the Card Library Open **Card Lookup** to search across all five decks. You can search by: * Card name * Alternate or translated name * Meaning * Theme * Goddess, angel, demon, or archetype * AGR and Kimbition keywords Keyword matches appear beneath relevant results so you can see why a card was included. ### Log Your First Spread Open **Pull Tracker**, then select a template or build your own spread. 1. Choose a template from the grid or select **+ Add Card** 2. Use **+ Add Section** to group related positions, such as Personality, Timing, or Appearance 3. Select a deck, card, orientation, and position for each entry 4. Add card-level notes 5. Select tags to categorize the spread 6. Write an overall synthesis 7. Select **✦ Log This Spread** ### Review Your Pull History Saved spreads appear in **Pull History**. You can: * Search across spreads, questions, positions, cards, and notes * Filter by deck and tag * Sort by date or number of cards * Expand or collapse individual spreads * Edit an existing spread * Clone a spread to reuse its structure ### Back Up Your Data After saving readings or custom meanings, select **Export Data** in the Pull Tracker. Save the exported JSON file somewhere secure, such as: * Google Drive * OneDrive * iCloud * An external drive * A private backup folder Use **Import Data** to restore your information in another browser or after clearing browser storage. --- ## Tips * The navigation bar remains visible while scrolling * The **↑** button appears in the lower-right corner after you scroll down * Use **⧉ Copy** to duplicate a card row during multi-card entry * Use **Card History Search** to find every spread containing a specific card * **Most Pulled Cards** displays the top eight cards with upright and reversed percentages * Pull History can combine deck filters, tags, sorting, and free-text search * Theme searches such as `water`, `shadow`, `healing`, or `desire` can surface relevant AGR and Kimbition cards * Export your data regularly because browser storage does not automatically sync across devices
